Télécharger le HTML de n'importe quelle page

Ce raccourci Safari s'exécute sur la page elle-même : pas de proxy, et ça marche aussi pour les sites qui s'affichent en JavaScript.

  1. Appuie sur Copier le code.
  2. Dans Safari, ouvre n'importe quelle page, appuie sur Partager puis Ajouter un signet (nom : « HTML »), et enregistre.
  3. Ouvre tes signets, appuie longuement sur « HTML », puis Modifier. Remplace l'adresse par le code copié (efface tout, puis colle) et enregistre.
  4. Sur la page à capturer : touche la barre d'adresse, ouvre les signets et appuie sur « HTML ». Un bouton bleu ⬇ HTML apparaît : appuie dessus, puis « Enregistrer dans Fichiers ».
